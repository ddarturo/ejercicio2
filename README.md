# ejercicio2

Formulario de registro accesible con validacion HTML5 y JavaScript.

## Ejecutar localmente

Abre `index.html` en un navegador. El proyecto no necesita dependencias ni proceso de compilacion.

## Despliegue

El workflow de GitHub Actions publica automaticamente la raiz del repositorio en GitHub Pages cada vez que se actualiza la rama `main`.

Para activar Pages en el repositorio:

1. Abre **Settings > Pages**.
2. En **Build and deployment**, selecciona **GitHub Actions**.
3. Espera a que termine el workflow `Deploy to GitHub Pages`.
